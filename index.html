BakungKron

Beautiful modern new tab page for Chrome. Search, bookmarks, shortcuts, and more — all in one elegant glassmorphism dashboard.

Download Source Code
Chrome Extension Manifest V3 Vanilla JS

Features

Everything you need in a new tab page

Search Engine Selector

Switch between Google, Bing, DuckDuckGo, YouTube, GitHub, Wikipedia, Reddit, and Amazon with live suggestions.

Bookmark Grid

Auto-fetches your Chrome bookmarks with folder navigation. Add and organize bookmarks directly from the new tab.

Shortcuts

Create quick link shortcuts with custom colors for instant access to your favorite sites.

History

View and clear recent browsing history right from your new tab page.

Customizable

Dark/Light mode, 10 accent colors, 16+ background gradients, and custom image upload.

Clock & Greeting

Time display with auto-greeting based on time of day and searchable search history.

Installation

Get started in seconds

Chrome / Edge / Brave
1
Download
Go to Releases and download the zip.
2
Extract
Unzip the downloaded file.
3
Load Extension
Open chrome://extensions/, enable Developer mode, click Load unpacked, and select the folder.
4
Enjoy
Open a new tab — BakungKron will appear!
Firefox
1
Open about:debugging#/runtime/this-firefox
2
Click Load Temporary Add-on and select any file inside the extracted folder.
